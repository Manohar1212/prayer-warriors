# Funds Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transparent offline group accounting with an audit trail and CSV reports, per the spec.

**Architecture:** Six admin-only Cloud Code writers over a pure handler with injected repositories, each writing an audit row; the app reads all ledger rows with the Parse SDK and computes balances, month summaries, and reports client-side with tested pure functions.

**Spec:** `docs/superpowers/specs/2026-09-08-funds-design.md`

## Global Constraints

- All earlier Global Constraints apply. Messages are exactly the spec's strings.
- Money is integer paise end to end; only the formatter and the amount input touch rupees.
- The app never writes `Contribution`, `Expense`, or `FinancialAuditLog` directly.
